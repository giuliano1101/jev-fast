# Working with jev-fast

Read [the current other-AI handbook](docs/other-ai-real-testing.md) first for the shared public service: exact schemas, short-connection continuation, real browser/Android examples, and UNKNOWN handling. [The quick start](docs/quickstart-agent.md) covers new installations; operator setup is in [the control panel manual](docs/control-panel.md) and [CLI/MCP manual](docs/cross-machine-cli-mcp.md).

- Windows-local browser has a separate four-tool stdio MCP at `dist/src/local/main.js`, setup via `npm run local-browser:setup -- --mode launch|attach|extension`. See docs/local-browser.md. Public `jev.browser_*` still runs on the Mac; never label it Windows-local execution. The local bridge sends only choices to public Jev and executes official Playwright MCP on the client machine.
- Service recovery uses persisted operator intent and original profile, never mock fallback or ledger resets. Watchdog jobs must adopt verified existing PIDs before activation; manual off remains authoritative. See docs/service-recovery.md.
- Native desktop executor is a separate 14-tool stdio MCP at `dist/src/desktop/main.js`; compile with `npm run desktop:build`. See `docs/native-desktop.md`. It can pair with the existing real `jev.choose_action`; the original shared public profile still only binds android. The additive public Mac bridge now exposes `host=mac` (`desktop` alias) without changing/restarting that coordinator; read docs/mac-public-automation.md and verify mac_available plus actual desktop_status permissions. Do not restart shared processes to enable hosts or confuse Windows read-only CI with physical Windows App acceptance.
- Current local CLI/stdio exposes 13 business tools: six legacy fixture tools, `jev.choose_action`, `jev.browser_open/observe/act/close`, and `jev.host_tools/act`. Public MCP exposes those plus `jev.network_status`, `jev.request_status`, `jev.release_connection` (16 total). Network business arguments are `{request_id, params, continuation_token?}`; local arguments remain unwrapped. Read actual schemas before calling.
- Real browser tools open arbitrary HTTP/HTTPS URLs in isolated headless Chromium, separate from everyday Chrome profiles. Host tools use operator-configured MCP backends; current deployment includes `android`, plus the separate additive `mac` bridge for real Mac GUI and daily Chrome. Native GUI operations use that host; legacy browser_* remain headless. Actual OS permissions and postconditions govern support. Observe actual postconditions; a signed Jev decision or returned tool call alone is not task completion. If `navigation_pending`, observe again before deciding what happened.
- The shared original Mac service is `/tmp/jev-501`, provisioned for real remote Jev with usage-only metering. Reuse it. Do not stop/restart it during cleanup, change provider, request its key/profile/approval from the user, reset counters, or alter historical ledgers. Only close/release your own contexts.
- The deployed relay enables trusted `autoAdmitAi: true` and `allowContinuations: true`. New AI initialization is admitted immediately when the selected device is ready. Cache the privately returned `continuation_token` from network_status automatically and pass it on all later business/status/release calls, including across DELETE/new MCP transports. It binds the original logical owner and generation; names and guessed CIDs cannot resume identity. Never print the token or call the operator API to self-approve. End normal work with release_connection; manual AI/device/global off remains authoritative.
- The authorized 2026-11-02 heartbeat maintenance is complete: relay device leaseMs is 30000 and the original connector uses TLS keep-alive. Old continuations are invalid; establish a fresh independent connection and never replay the completed Windows decision. This is not a guarantee that every sub-30-second outage preserves an owner: the local 5-second owner fence still applies. See docs/reports/2026-11-02-heartbeat-maintenance.md.
- No paid count/cost/expiry cap, fixed step count, global session count, queue length, or default AI/queue/business-result TTL is imposed by the current deployment. Optional caller/operator budgets remain explicit. Same-session action leases, per-physical-host ordering, heartbeat fencing, TLS, 16 MiB transport guards and UNKNOWN quarantine are correctness/resource rules. Upstream and actual host resources can still fail.
- New installations default to offline mock and manual/default-off admission. A clone, panel start, or available key does not authorize hosted spending. Operators provision private identities, certificates and an explicit spending policy; agents never create/reset approvals. Current public policy does not require other AIs to request fresh paid approval.
- Start a local coordinator before its stdio facade. Use Node24.19+ and absolute executable/entry/credential paths. scripts/env.sh is specific to the original Mac. Use doctor, policy status, schemas --json and actual health/tool results to verify the installed build and capabilities.
- Preserve request_id, goal_id and idempotency_key across uncertain responses. Query original status first. UNKNOWN means stop and preserve evidence, never replay with a new key or clear audit to recover. Continuations are memory-only and can expire on relay restart/revocation; losing one does not establish that no physical action occurred. FALLBACK does not authorize claiming another executor's work as Jev.
- Keep credentials, private profiles, raw account/device data and runtime ledgers out of Git, chat and public reports. Local stop prevents new work and cancels/drains owned operations; it cannot reverse completed effects or disable unrelated host tools.

Current public tests include independent real Example website sessions, Jev navigation, short-client recovery and Android HOME/foreground verification. They do not guarantee all websites or applications; see [the current report](docs/reports/2026-11-02-unrestricted-service.md). Older synthetic-only/bounded-stage reports are historical evidence, not the current contract.

For code changes, use applicable Superpowers engineering skills, test meaningful behavior, and run `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:integration`, and `npm run test:safety` before claiming completion. No hosted calls in ordinary tests/CI. Document scope limits alongside results.
