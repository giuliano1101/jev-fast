# S6 真实 API 与浏览器测试

状态：**本轮实验完成，用户授权总计不超过 USD 3**。2026-10-30 已验证 TypeSafe 正式 API：新密钥的普通与 zstd 请求均通过；先前一条认证失败请求单独保留。S0–S5 默认 mock 行为保持不变，S6 通过明确的本机临时文件路径读取密钥，不自动读取环境中的其他密钥。

正式结果：Jev 25/30 成功，普通 computer use 18/18；共同 18 项中 Jev 成功 16 项。这 16 项的配对耗时比中位数为 5.49×，困难组 Jev 成功率只有 50%。五次低置信度停止仍然计为失败。完整分档和方法限制见 [真实对比报告](../artifacts/live/report/summary.md)。

本次授权覆盖当前比较实验的请求和重试。持久预算每次 HTTP 尝试先预留 USD 0.01，最多 300 次；跨进程重启不清零。最初 smoke 建立两小时实验窗口，后续运行沿用，不延长。已知费用按服务返回用量与 [官方定价](https://docs.typesafe.ai/models) 计算；未知用量继续保留预留，不视为免费。

正式对照为当前 Codex 会话的普通 computer use 与 Jev 决策加本地浏览器执行。普通会话增量成本不可得，不能计成 0。另有直接脚本辅助基线。三档难度、两类任务为本机合成网页中的真实浏览器点击/填写/选择/滚动，不使用用户账户或真实业务数据；不声称覆盖原生 macOS 应用。

分级试验使用独立 12 步/120 秒研究工具，复用已验证的 provider 与绑定/过期检查，**不是已交付的 8 步 P0 引擎性能验收**。默认固定置信度阈值 0.9。失败、拒绝和中断均保留；方案见 `superpowers/plans/2026-10-30-live-comparison.md`，产物在 `artifacts/live/`。

## 本轮已固定范围

- 模型与账户：TypeSafe Jev，固定 `jev-1.14.0`；不使用漂移别名。
- 允许外发：仅本项目合成 fixture 的最小脱敏语义状态和候选描述；没有真实页面、截图、个人资料。
- 请求上限 300 次（含重试），总额度 USD 3。实际累计 115 次，保守预留 $1.15；已知 token 估算 $0.003050334，另一次 401 用量未知。预留不是实际扣费，估算不是账单。
- 主对照为当前 Codex 会话普通 computer use，辅助对照为直接脚本；没有接入第二个付费模型。
- 密钥通过本机隐藏输入写入受限临时文件；不要粘贴到聊天、源码、配置文件或命令历史。

## 测试前冻结

锁定模型、候选构造、阈值、任务 seed、成功 oracle 和预算。校准 seeds 101–105 与评测 seeds 1–5 分离。真实与 mock 产物分目录。每次重试提前计入请求/费用保守预留；未返回 usage 的请求标 unknown，不当零费用。

2026-10-30 优化后，大于等于 1 KiB 且压缩有收益的请求使用官方 SDK 同款 zstd 编码。本轮已验证服务接受此编码；小请求保持未压缩 JSON。压缩只减少传输字节，不作为 token 计费折扣，也不引入自动重试或扩展预算。

## 结果判断

保留全部失败与回退；成功率分母为所有启动任务。确认无安全违规后，才讨论总体端到端 p50/p95、成功率和包含回退的总成本。无真实主 agent 基线时，不能得出“加速 agent”的结论。

本轮两次校准 seed 101、102 均保留；正式 seed 1–5，普通 computer use 为同任务 seed 1–3。正式评测前冻结源码与执行文件 hash，之后未按正式失败调参重跑。最终离线检查见 `../artifacts/live/offline-verification/final/`。复算命令见报告末尾，不需要再次调用 API。
