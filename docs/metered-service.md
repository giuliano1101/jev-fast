# 本机 Jev 用量计量

保留既有 usage-only 策略、逐 HTTP 尝试的持久计量、身份/请求关联、token 与已知费用、未知 usage 标识。删除 CLI/MCP 接入层不会清零或迁移原私有账本，也不新增金额、次数或到期限制。

每次请求先记录尝试，重试是独立尝试；重复业务命中已存结果不应再次调用模型。响应答案无效但带有效 usage 时仍记录。网络中断或缺失 usage 计入未知，不能按零费用或保守预留冒充实际账单。

价格按该次可信配置/回执保存，不在新文档沿用历史模型价作为现价。用量统计不是供应商最终账单；共享身份也不能自动解释为每个 AI 的精确独立费用。每台主机应使用自己的配置、身份和状态目录。

保留的模型网关位于 `src/remote`，它是决策/计量基础设施，不是已移除的 Jev 业务 CLI/MCP 服务。不应将本机操作员能力当作任意 AI 可用的业务入口。新安装默认离线，实际托管调用由该主机已有配置决定。

历史只计费设计与测试见[原计量报告](../artifacts/metered-service/report.md)，其中的公网接入方式仅属历史。
