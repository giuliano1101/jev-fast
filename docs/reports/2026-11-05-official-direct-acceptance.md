# 官方直连、本机执行与连续流程：改进和验收

## 改进

默认入口从历史 service/profile/网关/MCP 后端，切换为 `direct/index.mjs`。根包删除 MCP 依赖及 service/gateway/control 启动脚本；CI 只安装 direct 包，不再启动 MCP 浏览器后端。原生、直接 Playwright 库、Session、费用、物理幂等和学习模块保留。历史源码及报告保留追溯，不作为当前接入指南。

新增 BrowserWorkflow 复用一个宿主，减少每一步外层重新读源码、写 adapter 和分析回执的空档。导航/历史/标签页、具名控件、正文滚动、真实下载、字节解码及下载历史已有接口。布局稳定、只读过渡重试和 URL 参数语义比较处理实测遇到的加载问题，真实输入仍逐次 Jev 选择、新鲜绑定、持久记账与后验。

仓库 skill 是路径模板；`installCodexDefaults` 在目标机渲染模块/Node/Key 路径，备份并更新一个全局准则托管块，保留无关用户设置。新机 Key、GUI 上下文和系统权限需现场配置，历史费用授权不迁移。安装器没有网络、模型或 GUI 调用。

## 其他能力与限制

此前原 Mac 已实测原生日常 Chrome 点击、窄窗口截图、TextEdit中文赋值和保存文件字节，以及官方Choice/Noul同请求。辅助功能/录屏均在真实图形上下文为true；这不是其他机器权限的证明。Android MCP后端不纳入直连；Windows源码保留，本轮没有目标Windows实体机验收。

图片为雨后城市3000×2251、公园夏季1572×1167、山野1600×904，重新通过Chrome下载，SHA-256与前轮一致。公园不是四季拼图。许可分别为CC BY4.0（Molly Des Jardin）、CC BY-SA3.0（WiNG并保留Wpcpey署名提示）、CC BY1.0（Aless0Mu）。

最初新对话提示没有指定Jev或skill；第一条执行命令自动读取本机jev-direct skill，随后导入直连模块。该单次验证不保证所有未来上下文必然遵守；安装后应在新对话复核。
