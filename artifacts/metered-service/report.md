2026-11-01。操作员明确要求：“你不要设置付费限制，任何限制都不要！你只要计算他们用了多少费用就可以！”本机真实服务已切换为只计费模式：没有金额封顶、没有累计调用次数上限、没有预算有效期拦截。不是把限额调大；配置中没有这些限制字段。其他 AI 复用原 MCP 地址、自动接入，不再向用户索取模型 Key、profile 或新额度批准。

外层原 RequestBudget 不再用于 active transport；网关不再 configure/reserve 旧子预算；模型调用器在 metering 模式不检查付费次数、金额、审批截止时间或预留 token 费用。旧有有上限模式继续供其他安装使用。原父账本仍为8次、保守预留$0.08，文件 SHA256 与切换前完全一致；这些预留不是实际消费，也不再决定当前服务能否调用。

## 记账逻辑与准确范围

新增私有 `usage.sqlite`，每次 HTTP 尝试前以 SQLite FULL synchronous 事务写入独立记录；重试各记一笔。HTTP错误、答案格式不对或目标失败，也记录其可验证的顶层 usage。网络错误、缺失/无效usage和中断未完成记录明确计为 unknown，不删除、不计作免费；预写后未能实际发出也可能留下未知记录。

每条记录保存当时输入价格，后续改价不会重新给历史 token 定价。按 2026-11-01 核对的[TypeSafe官方模型页](https://docs.typesafe.ai/models)，Jev1.14输入$0.042/百万token，输出免费；521×0.042/1,000,000=$0.000021882。统计是按已返回usage计算的已知费用，不是供应商最终账户账单，未知请求可能另有消费。

费用可按 policy/网关 identity/request_id 关联。公网AI名称由relay展示，当前共享Mac网关identity相同，因此by_identity不等于逐AI姓名的独立账单；本轮未增加跨层名称字段。普通AI工具契约、所有权、幂等、UNKNOWN和动作后验不变。当前主接口仍只执行standard合成页面十二类任务，没有新增任意网页/桌面/手机控制能力。

## 修复、审查与回归

TDD 验证连续1,001次调用及模拟累计$42.042仍可执行，无旧次数/金额上限；本地TLS测试模拟单次$42账务记录可正常完成签名Jev回执，证明旧存储的$10校验也不再作为费用拦截。以上均为离线模拟，没有实际花费这些金额。持久化字段只要求非负有限费用，旧预算的上限校验不变。

测试覆盖重试/错误/缺失usage、记录重开、未完成请求未知、重复完成拒绝、历史价格、私有文件、普通模式兼容、重复业务请求不新增HTTP、同步/异步账务读写的原始截止时间。

最终代码的类型/lint通过；默认测试424/424、集成78/78、安全40/40、部署Python16/16，无失败/取消/跳过。默认套件含部分安全测试，不能将这些计数直接视为互不重叠样本。全部日志在[verification](verification/)，普通测试和CI不调用付费模型。
