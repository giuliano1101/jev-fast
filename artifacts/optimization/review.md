# 独立代码审查

审查范围：浏览器合并读取、状态校验与动作开始边界、请求压缩、预算与重试。审查者独立读取旧版快照与新代码，未启动付费 API。

发现一个 P2 回归：统一读取重构删除了原来状态读取异常返回 false 的行为，可能让尚未开始的操作进入 UNKNOWN。已恢复异常分类：无效状态或短暂读取故障返回 false；SENSITIVE_PAGE、OUT_OF_SCOPE 继续严格拒绝。新增真实浏览器测试确认最终校验失败抛 ExecutionNotStarted 且输入框没有被修改。

红绿验证：新增测试在修复前抛 UNSAFE_OBSERVATION 失败，修复后通过。审查者复查源码与编译产物，并使用无浏览器 stub 独立验证异常分类，确认没有剩余阻塞项。

首次两项优化的红绿验证：旧浏览器读取返回 revision 90001 而测试要求与旧状态对应的 90000，测试失败；合并读取后通过。旧 provider 没有 zstd Content-Encoding，新测试失败；增加无损编码后通过。

完整验收最初在受限环境中运行时，本地 IPC 启动被 EPERM 拒绝；此轮不记为通过。获准启动测试服务后完整重跑。所有最终检查以本目录 checks.json 和原始日志为准；first-pass 保留独立审查修复前的已通过版本检查，before 保留优化前基线。
