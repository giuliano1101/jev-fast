## 范围与预算

实际链路：本机 CLI 或 SDK stdio MCP → 本地 coordinator / Engine → 本机 loopback 双向 TLS 网关 → TypeSafe hosted Jev → 签名回执 → 本机独立 Chromium 合成页面。live 使用 `required_jev`，不接受 mock 路由；网关永远不持有浏览器控制权。

生成的证书/token 仅为本次临时试验身份，不是生产部署。不得打开跨机端口、修改用户日常浏览器、访问真实账户内容或开展 D/E 测试。

预算保存在新独立 SQLite 账本；每次 HTTP 尝试先预留 $0.003，30 次最多预留 $0.09，另有 $0.10 总上限和时间上限。记录目录固定，重启不能另建空预算；输出独占创建，不能覆盖失败记录。预热也占用预算。API key 只读已有私有文件，不写进报告或日志。

定价核查：[TypeSafe 官方模型说明](https://docs.typesafe.ai/models)，2026-10-30 读取，`jev-1.14.0` 输入 $0.042 / 百万 token，输出免费。按返回 usage 估算费用，未核对账户账单；未知用量保留保守预留，不按零计。

## 冻结题库

先进行一项独立预热：选择合成分类 beta（`select`，1 步）。预热不计入正式成功率，但费用计入总数。

| 难度 | task | 目标与成功后验 | 预期步数 | 正式次数 |
|---|---|---|---:|---:|
| 简单 | cancel | 在模拟表单按取消，页面确认 cancelled 且 task_complete | 1 | 3 |
| 中等 | correction | 先空提交触发校验错误 → 填写 seed 对应的模拟邮箱 → 再本地模拟提交；后验确认完成 | 3 | 3 |
| 复杂 | form | 填写 seed 对应模拟名称 → 下一步 → 选择 beta → 本地模拟提交；后验确认完成 | 4 | 3 |

使用固定的交错顺序分散先后影响，并交错 CLI/MCP 入口。语言 en；实际顺序、seed、接口写入 rows.json。每题新建隔离 session，沿用原 8 步/60 秒公共上限内的更小题目步数上限和 15 秒 goal 预算；原 2 秒快照/许可期限、0.90 置信门槛不放宽。全部成功时，含预热预计 25 次决策请求；最多剩余 5 次作为网关已有有限重试或重新观察的空间，绝不超过 30 次硬上限。

## 统计方法

- 完整工作流计时从 open_session 前到 close_session 后，包含观察、执行、查询、幂等验证及入口通信成本；同时记录扣除幂等查询的 e2e_excluding_duplicate_ms 和 run_goal 时间。服务启动和 MCP 初次连接不计入单题；usage 采集收尾计入完整时间。CLI 进程启动开销属于该入口的实测成本。
- 每次 hosted 调用记录响应时间、HTTP 状态、置信度和严格解析的 usage；不记录请求正文、认证头或原始响应。仪表读响应副本会带来少量观测开销，明确保留此限制。
- 正式成功率分母固定 9 项；失败、超时、因总限额未执行的项目分别展示。无法确认的结果不得标成功。
- 对已返回结果的同键请求检查幂等：返回原结果且预算不增长，不作为新试题或独立成功样本。
- p50/p95 使用 nearest-rank（排序后第 ceil(p*n) 项）；全部已执行正式题和成功子集分别统计。9 个正式样本中 p95 等于最大样本，不代表长期尾延迟。
- 记录总 HTTP 尝试、中央预留、已知 token 费用、未知用量和拒绝原因；超时或未给 usage 的调用不当作免费。
- 所有动作核对账本中的 `route: jev` 回执；没有有效许可不执行。结束后验证停止、撤销临时身份，并保留审计。

## 解释边界

这是单台 Mac 上的 hosted 接线验收；loopback 不包含跨机器/VPN 延迟。三档难度只指固定合成步骤数量，不能外推真实网站或手机稳定性。没有新增普通 computer use 对照，不能从本测验计算加速比，也不能把 S9 的 2.97× 移用到这里。

正式题不因失败重跑、换键补成功或临时降低阈值。认证失败、总预算到限或 UNKNOWN 需安全停止；后续诊断若仍在授权范围内须单列，不能覆盖原始成绩。
