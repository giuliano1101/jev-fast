# S9 手机试验协议与题目

2026-10-30 冻结，正式计时前编制。实体 OPPO Find X3 Pro / Android 12，现有 Mobile MCP 1.0.8。首批为只读导航、搜索、更正搜索与跨应用恢复；不覆盖购买、聊天、拍摄或发布。

| 编号 | 难度 | 题目 | 独立完成条件 |
|---|---|---|---|
| M1 | 简单 | 从设置主页打开蓝牙详情 | 蓝牙详情标题、开关控件和返回入口同时可见；不切换开关 |
| M2 | 简单 | 打开连接与共享详情 | 页面标题及飞行模式、USB 网络共享条目可见 |
| M3 | 中等 | 搜索“字体”，进入字体与显示预览 | 预览标题、字体大小和显示大小控件可见；不点击应用 |
| M4 | 中等 | 搜索“通知”，找到设备和应用通知访问列表 | 经过特殊应用权限入口，最终标题与权限说明标记可见；不修改权限 |
| M5 | 复杂 | 完成 M3，切到浏览器打开 Example Domain，再返回原字体预览 | 浏览器原生工具栏标题曾验证为 Example Domain，最后重新验证字体预览；不以打开链接回执替代验证 |
| M6 | 复杂 | 先搜索并查看字体预览，返回、清空查询，改搜通知并进入通知访问列表 | 字体预览曾验证，最后通知访问列表成立；不能把旧查询残留当成新查询成功 |

难度是本次有限题库的相对等级：简单单步目标选择，中等输入与嵌套导航，复杂包含历史核对、查询纠正或跨应用恢复。它不代表所有手机任务的难度分布。

## 对照定义

普通 Mobile MCP = 当前 Codex 助手根据实时观察选择动作，再调用 Mobile MCP。Mobile MCP 自身不是推理模型。Jev 接入也必须通过同一 Mobile MCP 工具层；直接执行、Jev 决策、teacher 接管分项统计。程序写死路径的结果不能称为真实 Jev 结果。

每题计划每组两轮。起点统一为已验证的设置主页，复位不计时；所有正式尝试均保留，包括失败和 UNKNOWN。计时从任务开始到完整验收，包含助手思考和宿主工具调度；另列 MCP 工具内耗时、物理动作数和观察数。不能用这一工作流比值推导纯模型推理加速。

训练/能力探测与正式测试分开。任何有学习的混合组须另计首次示范、验证和规则生成成本。预算批准前不调用付费 API；不以模拟模型结果补齐对照。若两组未交错执行，报告必须注明顺序、学习及设备负载偏差，不能宣称统计显著。

## 观察与隐私

手机浏览器当前只能通过 Mobile MCP 读取原生工具栏，正文未暴露；M5 只验收工具栏标题及应用恢复，不声称网页正文测试成功。设置搜索会异步刷新；点击回执只表示工具返回，最终页面必须另读。

设备标识、通知内容、网络名称、账号信息和应用清单仅保存在忽略的本机运行目录；仓库仅提交公开题目、语义页面类别、工具名、计时及成功判据。首次权限/条款弹窗导致计算器和时钟暂不纳入题库，且不计为 Jev 或基线执行失败。
