# 本机 Codex 默认操作准则：Jev 优先

**操作本机 App 和 Chrome 时，适用且就绪的任务优先使用 Jev 官方直连执行器。** 此规则适用于加载本机全局准则的 Codex 对话和自动任务，无需用户每次指定 skill；用户当次明确指定的工具优先于此默认偏好。

执行前读取 `{{JEV_CODEX_HOME}}/skills/jev-direct/SKILL.md`，导入 `{{JEV_ROOT}}/direct/index.mjs`，使用 Node 宿主 `{{JEV_NODE}}`。日常登录态 Chrome / App 优先用原生 Session；不依赖个人登录态的网页任务优先用 BrowserWorkflow 与独立本机 Chrome。使用本机已配置的官方 TypeSafe Key，不启动已退役的 Jev MCP/CLI、中转或旧网关。

先按能力与实际状态选路：执行器已支持、权限就绪且任务可由有限候选和后验表达时使用 Jev。观察、准备、截图和核验优先复用同一执行器。确定性专用服务连接器、普通编码、文件处理和已有 API 读写直接使用对应工具，无需为此强加 GUI 或模型决策。

Jev 不支持任务、不可用，或已确认在物理输入前失败且没有未决动作时，可以在原任务授权内使用可用的 Computer Use、专用连接器或其他本机工具；记录切换原因、实际执行器和结果，不冒称是 Jev 完成。先检查真实图形上下文与现有权限，避免因沙盒假阴性重复请求授权。不因已确认不适用而反复调用或让用户逐次批准工具选路。

走 Jev 路径时，每次输入保留观察→选择→新鲜绑定→持久幂等→独立后验；候选是单步备选，不是整段脚本。低置信、状态漂移或后验失败先只读核查，不能把一次拒绝或失败当成无条件重试许可。

原生 Session 共用该安装默认物理主机账本和租约。保留 goalId/idempotencyKey；UNKNOWN、已派发但未确认、未决物理输入或遗留锁一律停止新输入并保留证据，不通过换工具、键、目录或安装重放。只有可靠只读证据澄清结果后，才能规划已授权的后续新意图。

Key 由本机私有模块读取，不进入聊天、参数、日志或 skill；保留所有用量与失败记录。该偏好不新增付费封顶、不重置历史账本，也不扩大任务、数据传输或系统权限授权。新机器单独配置其凭据与权限，历史测试额度不自动迁移；上级指令和用户当次明确要求始终优先。
